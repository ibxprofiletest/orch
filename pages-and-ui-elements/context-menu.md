# Context Menu

The Context menu in Orchestra provides quick access to **key actions for various entities and elements**. Different entities and elements have different options in their context menus, which you can open by right-clicking on various interface elements or by clicking on the `···` icon.

Below is the list of entities and elements where the **Context menu** is available:

* [chats-page](https://docs.orch.so/pages-and-ui-elements/chats-page "mention")
  * Workspace name;
  * Chats in the chat list;
  * Header section in the Unread tab of the chat list;
  * Chat header;
  * Message in chat;
  * Breadcrumbs in chat header;
  * User avatar and name in chat;

* [tasks-page](https://docs.orch.so/pages-and-ui-elements/tasks-page "mention")
  * Workspace name;
  * Custom Views;
  * Project block header;
  * Projects in the [#projects-block](https://docs.orch.so/tasks-page#projects-block "mention");
  * Teams in the [#teams-block](https://docs.orch.so/tasks-page#teams-block "mention");
  * Project, view, or team header;
  * Layout tabs in project, view and team;
  * Tasks in list and kanban views;
  * Fields values in list and kanban views;

  * Workspace name;
  * Teams in the [#teams-block](https://docs.orch.so/teams-page#teams-block "mention")
  * Members in the [#members-section](https://docs.orch.so/teams-page#members-section "mention")

* [info-sidebar](https://docs.orch.so/pages-and-ui-elements/info-sidebar "mention")
  * `···` icon in the top right corner of the block;
  * Field values in the [#info-tab](https://docs.orch.so/info-sidebar#info-tab "mention");
  * Subtasks and Related tasks in the [#info-tab](https://docs.orch.so/info-sidebar#info-tab "mention");
  * Attached files in the [#info-tab](https://docs.orch.so/info-sidebar#info-tab "mention");
  * Member section in the [#members-tab](https://docs.orch.so/info-sidebar#members-tab "mention");

  * Attachments in the [#attachments-tab](https://docs.orch.so/info-sidebar#attachments-tab "mention")
