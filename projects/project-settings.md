# Project Settings

Each project in Orchestra has its own settings. To **access project settings**:

* Go to the [chats-page](https://docs.orch.so/pages-and-ui-elements/chats-page "mention") or [tasks-page](https://docs.orch.so/pages-and-ui-elements/tasks-page "mention") and select the project you need;
* Click the `Info` icon in the top-right corner of the screen;
* In the Info block that appears, click the Settings tab.

In the project settings, **you can**:

* Manage [fields](https://docs.orch.so/projects/fields "mention");
* Set [#project-privacy](https://docs.orch.so/key-project-features#project-privacy "mention");
* Set time for [#task-automatic-archiving](https://docs.orch.so/key-project-features#task-automatic-archiving "mention");
* Enable or disable [#chats-automatic-following](https://docs.orch.so/key-project-features#chats-automatic-following "mention").
